# Kids Cooking Game

A small, text-free cooking game for young children, made with [Phaser 4](https://phaser.io/),
Vite and TypeScript. The child makes a pizza from start to finish: roll the dough, spread the
sauce, sprinkle the cheese, add toppings, bake it and feed it to the character. There is no text
to read, no way to fail and no time limit. It is built for touch screens held sideways (landscape)
and can be installed as an offline web app (PWA).

Play it at: https://yonatan1feldman-prog.github.io/kids-cooking-game/

## Run it locally

Requires Node.js 20 or newer.

```sh
npm install
npm run dev        # dev server: http://localhost:5173/kids-cooking-game/
npm run build      # production build into dist/
npm run preview    # serve the production build: http://localhost:4173/kids-cooking-game/
```

The game is served from the `/kids-cooking-game/` sub-path in every mode (see `vite.config.ts`).
Every push to `master` is built and published to GitHub Pages by `.github/workflows/deploy.yml`.
